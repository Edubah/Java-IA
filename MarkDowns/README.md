# Java-IA
BootCamp de Java

Objetivo desse bootcamp é impulsionar meus estudos em Java e consolidar os mesmo com IA.
Acredito que será de muita ajuda e me sinto motivado agora!

A princípio o minha jornada é criar 3 níveis de interação com IA, tentarei deixar o mais explicativo aqui.

1º - O Chatbot: Aqui é o passo inicial, aprender a consultar um "especialista". Ideia principal, eu pergunto, ele responde. Simples!
2º - Os copilotos: Aqui tentarei criar um assistente, tanto para meu serviço quanto para o meu dia a dia, ênfase no "tentarei" rsrs! O foco dele será procurar melhorias no meu desempenho ou ações.
3º - Os Agentes: Aqui é o ápice das minhas skills, tentarei criar alguém que delegará tarefas, o meu despachante praticamente. "Eu explico e ele resolve!"

Tentarei e vou fazer (Já me motivando) a deixar uns READMEs separados para cada processo do BootCamp.
